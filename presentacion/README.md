# Presentación

Aquí va el PPT de la exposición del Grupo 3 para la HACKACOES.

## Convención de nombres

```
HACKACOES_Grupo3_Liquidaciones_vN.pptx
```

Subir una versión nueva en lugar de sobrescribir la anterior (`_v1`, `_v2`, …), para que quede el historial de cómo evolucionó la presentación.

## Contenido sugerido

1. **El problema** — información dispersa, demoras en la búsqueda, trazabilidad débil.
2. **La propuesta** — automatización del módulo de Liquidaciones.
3. **Demo** — recorrido por la aplicación.
4. **Arquitectura** — React + Vite en el frontend, FastAPI en el backend.
5. **Resultados e impacto** — tiempo ahorrado, trazabilidad ganada.
6. **Próximos pasos.**

> Nota: la carpeta se llama `presentacion` sin tilde a propósito. Los nombres de archivo con acentos se comportan distinto entre Windows, macOS y Linux, y en un repo compartido eso genera conflictos difíciles de diagnosticar.
